# The Round Door Hobbit Study

A family read-aloud unit study for J.R.R. Tolkien's *The Hobbit*, in a single self-contained page.

**Live site:** https://somersetnomad.github.io/round-door/

Twelve illustrated subjects, each with interactive activities: narration, literature, geography, history, science, maths, art and music, cooking, character, drama, notebooking and outdoor play. Progress and notes save in the browser on each device.

All illustrations are original and drawn in code; summaries, riddles and activities are written fresh. No text from the book is reproduced.
